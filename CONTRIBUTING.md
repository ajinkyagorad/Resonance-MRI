# Contributing

Start with README.md and AGENTS.md, then choose a scoped item in docs/ROADMAP.md.

AI-assisted contributions are welcome. Include the concrete problem, implementation, physics references where relevant, relevant checks, and actual Unity before/after renders. State what was measured on a headset and what was checked only on a server.

Keep generated concepts in docs/design-studies and implementation renders in docs/renders. Preserve one simulation clock and the distinction between physical space, signal time and spatial-frequency space. Keep proprietary SDK content in package dependencies and preserve third-party notices.

Submit a pull request. Never include signing material, API tokens, personal feedback logs or engine caches.
